# あいち電鉄 — 愛知めぐりすごろく

愛知県の92駅をめぐって物件を買い、いちばんの大金持ちをめざす「桃太郎電鉄」風のすごろくゲームです。
地図・キャラクター・アイコン・サイコロ・カードの絵はすべて **SVG** で描いています（画像ファイルなし）。

## 遊び方（モード）

| モード | 内容 |
|---|---|
| ひとりで練習 | 1人で遊ぶ動作確認モード。**デバッグ**ボタンで、サイコロの目の指定・お金/カードの追加・貧乏神のON/OFF・目的地の変更・ワープ・決算の即時実行ができる |
| CPUと対戦 | 人間 + CPU 1〜3体。CPUは1体ずつ「よわい／ふつう／つよい」を選べる |
| みんなで対戦 | **同じパソコン**で2〜4人が交代で遊ぶ（CPUを混ぜてもOK） |
| CPU観戦 | CPUだけで対戦させて眺める。「はやさ」を上げると結果まで一気に進む |

- あそぶ長さは 1年（おためし）／3年／5年／10年。1年 = 12か月で、3月の終わりに**決算**があります。
- 1人の番が終わるたびに自動保存されます。タイトルの「つづきから」で再開できます。
- スマホ・タブレットでも遊べます（地図はドラッグで移動、ピンチ／ホイールで拡大縮小、駅をタップで物件情報）。

- 駅は全部で **92駅**。すべて物件のある **物件駅**（紫色、物件 503件）です。実際の位置で約3km以上はなれた駅だけをえらんだので、名古屋の町なかは駅が少なめで、奥三河は遠くなります。近すぎる名所は近くの駅の物件にまとめています（大須観音は栄、鶴舞公園は金山、のんほいパークは二川、湯谷温泉は鳳来寺、恋路ヶ浜は伊良湖岬 など）。

- 道は実際の鉄道（JR・名鉄・地下鉄・愛知環状鉄道・飯田線・渥美線など）と道路、フェリーの航路（師崎・河和〜日間賀島・篠島、篠島〜伊良湖、一色〜佐久島）をもとにしています。

- 愛知の名物（名古屋めし、焼き物、祭り、温泉、島など）を物件にしています。小さな駅の一部は「◯◯の喫茶店モーニング」など、愛知らしさの穴うめです。

## ルールのまとめ

1. 自分の番に **カード**を1枚だけ使えます（使わなくてもOK）。
2. **サイコロ（ふつうは2個）**をふると、止まれる場所が光ります。**行きたい場所をタッチ**すると、そこまで駒が自動で進みます。
3. 止まったマスの効果が起きます。
   - 青マス = お金がもらえる（1年目は400〜800万円）/ 赤マス = お金をとられる（1年目は200〜600万円）/ 黄マス = カード / 青緑マス = ランダムなできごと
   - **季節**: 夏（6〜8月）は青マスのお金が2倍・赤マスは半分。冬（12〜2月）は赤マスでへるお金が2倍・青マスは半分。
   - **年がたつほど**、マスや目的地でもらえるお金・へるお金が大きくなります（1年ごとに＋50％。画面上の「マスのお金×1.5」などで見られます）。
   - **物件駅**に止まったら物件を買えます。**カード駅**に止まるとカードがもらえます。
   - **カード売り場**のある駅（名古屋・栄・一宮・岡崎・豊田・蒲郡・豊橋・セントレア）では、お金でカードを買えます。
4. 地図の旗が**目的地**。いちばんに着くと大きなボーナス。通りかかった場合もそこで止まります。着くと新しい目的地が決まります。目的地は、いちばん近い人から **12〜45マス先** の駅からえらばれます（マスが多いぶん、遠すぎると遊びのテンポが落ちるため）。
5. 目的地に誰かが着くと、目的地からいちばん遠い人に**貧乏神**がつきます。番の終わりにお金・カード・物件をうしないます。貧乏神がついた人が**ほかの人と同じマスに止まる**と、その人になすりつけられます。
6. **決算（3月の終わり）**に、物件の「価格 × 利回り」が毎年入ります。**1つの駅の物件をぜんぶ買う（独占）と、その駅の物件の利回りが2倍**（収入も2倍）。駅の情報や買い物の画面でも、2倍になった利回りと年収が出ます。
7. 自分の物件がある駅に止まると**増資**できます。価格が元の半分ずつ上がり（最大3回）、収入も増えます。
8. **食品日本一**: 2年目から、決算のたびに名物の食べものが2つ選ばれ、持ち主に臨時収入が入ります。
9. 決められた年数が終わったとき、**資産（お金 + 物件の価格）**がいちばん多い人の勝ち。

### 物件の値段と利回り
- 有名な場所・お店・工場ほど、値段が高くなります（お城・工場・空港・神社・タワーなど）。最高額は**名古屋城の200億円**です。
- 1つの駅の物件は、**安い順**にならびます。
- 利回りは、安い物件ほど高く（50%〜90%）、高い物件ほど低く（1〜4%）。名物度（隠しデータ）が高いほど高めで、**10%以上は5%刻み**です。

### カード（11種類）
急行・特急・新幹線（サイコロが3〜5個）、ろく（2個とも必ず6）、ワープ、**足踏み**（その場にとどまって買い物・増資）、足止め、お祓い、ご祝儀、半額セール（買い物・増資が半額）、買収。手札は6枚までです。

## エディター（タイトルの「エディター」）

- **マップエディター**: 上の「マップ」で編集するマップをえらびます。マスをポチポチ押して（なぞって）作ります。「線路をおく」で色（青＋・赤−・カード・イベント・線路だけ）をえらんでぬる、「駅をおく」で空いたマスに駅を置く・駅を押して別の場所へ動かす、「消す」で消す。となりあうマスは自動で線路がつながります。「スタート」でスタートの駅、「コピーして新しく作る」で自作マップをふやし、「このマップで遊ぶ」で遊ぶマップに決めます。用意されたマップは書きかわらず、変えて保存すると「（改）」の自作マップとして保存されます。自作マップはこのブラウザ（localStorage）に入り、「書き出し/読みこみ」でほかのパソコンへ持っていけます。
- **物件エディター**: 「駅ごとに直す」では、駅の名前・地域・説明と、物件の名前・アイコン・価格・名物度を1行ずつ直せます。価格は「−」「＋」でも上げ下げでき、利回りと年収がその場で出ます。「全物件の一覧で直す」では、全駅の物件を高い順・安い順・利回り順にならべて、まとめて直せます。
- 保存先はブラウザです（`localStorage`）。「もどる」を押すとゲームに反映されます。「書き出し/読みこみ」でバックアップできます。

## 動かし方

ビルドや依存パッケージはありません。**`index.html` をブラウザで開くだけ**で動きます（`file://` でもOK）。
Webフォント（Google Fonts）を使うため、オフラインでは代替フォントで表示されます。

ローカルサーバーで開きたいとき:

```bash
npx serve .
```

### 設計のポイント

- **ルールと画面の分離**: `logic.js` / `ai.js` / `board.js` / `data.js` / `layout.js` は DOM を一切触らず、Node.js でそのまま動きます。1人の番の流れ `runTurn(state, driver)` に、画面（`app.js`）やCPU・テストを「ドライバ」として差し込む作りです。
- **状態は全部 JSON**: ゲームの状態は素のオブジェクトだけなので、そのまま `localStorage` に保存できます。乱数も状態の中（`state.rng`）で進めます。
- **盤面は固定**: マスの種類も位置も `js/mapdata.js`（またはエディターで保存した盤面）にそのまま書いてあります。
- **駅の追加・変更**: `js/stations.js` に1駅ぶん書き、エディターの「駅をおく」で盤面に置きます（盤面に置いていない駅はゲームに出ません）。
- **マスの数**: エディターでぬって決めます。自動で作り直すときは `node tools/genmap.js`（`STEP=3` で、一本道の止まるマスの間隔）。

## テスト

```bash
node test/validate-map.js     # 盤面の整合性（駅・物件・利回り・路線の交差・ラベルなど）。MAP=nagoya などで各マップ
node test/simulate.js 200     # CPU同士を200ゲーム。強さの階段（Lv1 < Lv2 < Lv3）も確認
```
